# Prioritizer

A simple, single-page task prioritization app. Add tasks once, then view and sort them three ways:

- **List:** drag to stack rank. "Suggest order" can re-rank from either matrix.
- **Eisenhower:** Do first, Schedule, Delegate, Drop.
- **Value / Effort:** Quick wins, Big bets, Fill-ins, Money pits.

Completed tasks stay crossed out for the day, then move to the Archive.

## Lists and sections

Each tab is a list. Lists can be split into sections, and a list can show its sections rolled up. Double-click a tab or section to rename it.

## Saving

- Everything saves automatically in your browser.
- In Chrome or Edge, click the folder icon (top right) to sync to `prioritizer.xlsx` in a folder you choose. The app then loads from and saves to that file. A green check means syncing; a red X means it needs attention.
- From the same menu you can download a copy or import a file. The Excel file has one sheet per list and is easy to edit by hand.

## Running it

It's one file with no build step. Open `index.html` in a browser, or use the hosted GitHub Pages link.
