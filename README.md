# Prioritizer

A simple, single-page task app for deciding what to work on. Add a task once and it shows up everywhere.

## Views

- **Focus:** today's short list. Pick 3 to 5 tasks with the sun button or by dragging from Up next. Unfinished ones are offered back the next day. Also shows everything you're waiting on.
- **Prioritize:** three lenses on the same tasks:
  - **List:** drag to stack rank. "Suggest order" re-ranks from either matrix.
  - **Eisenhower:** Do first, Schedule, Delegate, Drop.
  - **Value / Effort:** Quick wins, Big bets, Fill-ins, Money pits.
- **People:** one card per person, split into "Waiting on them" and "To discuss or do". Handy as a 1:1 agenda.
- **Archive:** a weekly recap you can copy into a status update, plus every completed task by day.

## Tips

- Type `@name` in a task to tag a person, like `Review promo doc @Brandon`.
- Open a task to mark it **Waiting on someone** or **Focus today**.
- Tabs are lists; lists can be split into sections. Double-click a tab, section, or person to rename it.
- Shortcuts: `N` to add, `1` to `4` to switch views.

## Saving

- Everything saves automatically in your browser.
- The folder icon (top right) can sync to `prioritizer.xlsx` in a folder you choose (Chrome or Edge). Green check means syncing; red X means it needs attention. The same menu has Download a copy and Import a file.
- The Excel file has one sheet per list and is easy to read and edit.

## Running it

One file, no build step. Open `index.html`, or use the hosted GitHub Pages link.
